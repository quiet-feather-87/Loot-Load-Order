## 📖 About

LOOT Load Order is an open source utility maintained by the LOOT development team. It reads the plugins and metadata present in a modded game folder, then calculates a recommended load order based on community masterlists and per-plugin rules. The tool reports missing masters, dirty edits, incompatible pairs and other common issues, and it can apply the sorted order directly to your plugin list. Recent builds improve metadata handling for large collections and speed up sorting on heavily modded setups.

If you came looking for a LOOT Load Order download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes.
